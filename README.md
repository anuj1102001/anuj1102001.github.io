# Anuj M — Data Analytics Portfolio

Personal portfolio featuring revenue analytics, operational reporting, and data quality projects.

## Publish

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/ (root)**, then save.

## Files

- `index.html`: portfolio content
- `styles.css`: responsive styling
- `app.js`: resume and contact interactions
- `Anuj_M_Resume.pdf`: downloadable resume

Update the files on `main` to update the published site.
